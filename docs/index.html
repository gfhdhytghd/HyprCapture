  1. 0.3.0

    LatestOct 8, 2026Hyprland 0.56.2v0.3.0-0.56.2

    Native scrolling screenshots, in-place editing, desktop pins, and Hymission Stage capture

    New

    • Native scrolling screenshots: scroll inside a selected region or window in the editor to grow a long image, revisit captured content, and keep annotations aligned with the page.
    • In-place screenshot editor through open_editor(): rectangles, ellipses, arrows, lines, pen, highlighter, numbered markers, mosaic, spotlight, undo/redo, and zoom/pan.
    • Movable, resizable multiline text boxes with a floating toolbar for font, pixel size, and color.
    • Desktop pins that stay above normal windows and then follow the normal save, clipboard, and thumbnail flow.
    • UI translations for Simplified and Traditional Chinese, Japanese, German, French, Spanish, and Korean, selected through the new language option.
    • Capture windows from Hymission Stage, center them in the editor, and match selection outlines to their displayed rounded corners.

    Faster

    • The capture overlay starts sooner: the Qt helper launches in parallel with compositor capture, and panels and icons are created on demand and cached.
    • Frozen screenshot artifacts are memory-mapped instead of copied pixel by pixel.

    Fixed

    • Recordings no longer hang when the compositor was started from a terminal; the recorder's stdin now comes from /dev/null (#25, contributed by Vedaru).
    • Nix build fixes for #29: read-only store paths whose owner is unmapped inside the build sandbox are now trusted (writable paths are still rejected), and supervised processes handle stop signals under BusyBox ash. A sandboxed build of the repository flake passed its tests locally; the reporter's own setup has not been verified yet.
    • Microphone-only recordings ignore changes to application audio, and only capture dropdown settings are persisted.
    • Toolbar icons now use Google Material Symbols and render sharply at any scale.
    • Fix region scrolling captures that stayed at their original size or misaligned during small movements and repeated text; foreground detail aligns scrolling text over a stationary smooth background, with safer history matching and fixed-header detection.
    • Flush pointer motion before forwarding touchpad scrolling so applications such as Zen receive input at the intended capture position.
    • Keep the captured window foreground separate from the real or blurred background, and preserve editable backgrounds after a scrolling capture.
    • Preserve top-origin monitor crops in region recordings (#32) and editor geometry when creating scaled desktop pins (#33).
    • Reset offscreen render state between monitor captures and stabilize asynchronous UI/audio regression checks.

    Upgrade notes

    • Remove the old in_place_edit_toolbar setting and bind hl.plugin.hyprcapture.open_editor() for editing. open() retains its confirmation behavior and quick() captures directly.
    • Build against Hyprland 0.56.2 and update both the plugin and Qt helper. Scrolling image matching adds an OpenCV dependency.
    • Update Hymission alongside HyprCapture to use the Stage renderer's exact selection radius; older Hymission versions use a scaled-radius fallback.

    Validation and remaining checks

    • Release build and automated regression coverage, including isolated GTK scrolling, scale-2 region stitching, independent backgrounds, and Stage selection geometry. A stationary-backdrop fixture preserves opaque foreground pixels exactly; it does not claim whole-image equality for a background that does not scroll.
    • Production-desktop kitty and physical touchpad/touchscreen acceptance remain pending after updating the plugin and helper. Dynamic or ambiguous page content may require recovering overlap.

  2. 0.2.8

    Sep 6, 2026Hyprland 0.56.2v0.2.8-0.56.2

    Audio recording, echo cancellation, and accurate video timing

    Recording

    • Videos keep the frames' real capture timestamps instead of accumulating repeated frames, so audio stays in sync.
    • Oversized automatic recordings prefer hardware HEVC encoding.
    • Audio modes, device selection, application audio capture, mixing presets, manual gain controls, and live level meters.
    • Echo cancellation through PipeWire WebRTC, plus a native DTLN-AEC candidate with a validated CPU selection policy and optional OpenVINO NPU support. Real-recording, speech-quality, and long-duration acceptance tests are still pending.
    • First-frame recording previews, a finalization animation, centered recording controls, and optional restoration of capture settings.

    Performance and reliability

    • Less window-capture work thanks to compact render targets and cached GPU exports.
    • Fenced window streaming, frame-bound input geometry, and checks on the capture target's lifecycle.
    • Better handling of rotated and scaled outputs, encoder/backend fallback, countdown cancellation, screenshot notifications, window selection controls, and narrow toolbars.

    Build

    • New build dependency: FFmpeg development libraries (libavformat, libavcodec, libavutil). Install the DTLN runtime and models with the included AEC scripts.

  3. 0.2.7

    Aug 7, 2026Hyprland 0.56.1v0.2.7-0.56.1

    Correct window backgrounds and transparency

    Fixed

    • Window screenshots keep the selected background mode; real and transparent output no longer fall back to follow-system.
    • Painted window backgrounds are clipped to the visible rounded frame, while transparent edge and shadow pixels are kept.
    • Window artifacts are rendered straight into an RGBA framebuffer through Hyprland's snapshot path, preserving client alpha without heuristic matte recovery.

  9. 0.2.1

    May 9, 2026Hyprland 0.55v0.2.1-0.55

    Hyprland 0.55 and better window shadows

    Improved

    • Faster window shadow synthesis that uses Hyprland-style shadow geometry and falloff.
    • Compositor window recordings stay on the compositor backend instead of silently falling back to visible GSR when alpha is unavailable.
    • Recordings keep window shadows and are cropped only when shadow removal is requested.
    • When the output cannot carry alpha, shadows are composited over the selected solid or follow-system background.

    Fixed

    • Lua fallback dispatch from the helper, and the overlay now fades out before window rendering and saving.

  10. 0.2.0

    May 5, 2026Hyprland 0.54.3v0.2.0-0.54.3

    Renamed to HyprCapture, fusion mode, and watermarks

    New

    • The project is now called HyprCapture.
    • Fusion toolbar mode: a single click captures fullscreen, and gestures combine region and window capture.
    • Configurable watermarks with built-in Activate Linux and HyperCam-style presets, plus position, size, and offset controls.

    Improved

    • Lower capture latency: the overlay closes without waiting for saving, clipboard, and thumbnail work.
    • Simpler region capture, updated toolbar icons and status, cleaner cancel and dropdown controls, and no window titles in window mode.
    • Installation steps and default helper path guidance for hyprpm.

    Fixed

    • Real-background window sampling.

  11. 0.1.0

    May 3, 2026Hyprland 0.54.3v0.1.0-0.54.3

    First release (as hyprshot)

    Highlights

    • Fullscreen, region, and window capture modes with a frozen compositor snapshot behind the overlay.
    • Fullscreen and region output at display resolution.
    • Window artifacts rendered by the compositor, including windows that are occluded or partly off-screen.
