# DTLN-AEC candidate assets

Only 256 and 512 units are supported. Models are MIT licensed by Nils L.
Westhausen; see DTLN-LICENSE.txt. The pinned upstream commit and SHA-256 values
are in src/audio/aec_policy.cpp. Personal recordings are never packaged.

The two golden files contain float32 little-endian output and every frame's recurrent states,
compressed with Qt qCompress (four-byte big-endian length + zlib). Regenerate
with scripts/generate-aec-golden.py and tflite-runtime 2.14.0 / NumPy 1.26.4.
The ten-second test signal is generated by src/audio/aec_fixture.hpp. It consists
of deterministic filtered noise, harmonics and an echo path, with far-only,
near-only and simultaneous intervals. It is synthetic speech-like input, not a
human speech corpus; passing it validates implementation and timing, not perceived
speech quality. The generator and signal are distributed under this repository's
license. The DTLN-derived output is distributed with the upstream MIT notice.

CPU runtime: TensorFlow Lite 2.14.0 with XNNPACK, one thread, no GPU or NNAPI.
The build script downloads checksum-pinned TensorFlow / CMake / PSimd sources;
TensorFlow's CMake build pins its other dependencies. Runtime dependencies and
licenses are retained in the candidate bundle. OpenVINO is optional and NPU-only.

The microphone path is mono at 16 kHz internally (approximately 8 kHz audio
bandwidth). Playback/system audio is not passed through DTLN. libswresample uses
an explicit 32-tap filter and phase_shift=10; its installed version is part of
the platform build. Benchmarking includes the 48/16/48 kHz resamplers.
